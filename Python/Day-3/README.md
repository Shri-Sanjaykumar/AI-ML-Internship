# Python Practice — Day 3

This folder contains the practical implementation of Python data structures and file handling completed during Day 3 of the internship.

---

## 📝 Concepts Practiced
- **Lists:** Managing ordered collections of student records.
- **Tuples:** Storing immutable subject definitions (`SUBJECTS = ("Python", "Math", "Data Science")`).
- **Dictionaries:** Structuring student profiles with key-value pairs (`roll_no`, `name`, `marks`).
- **Sets:** Tracking registered roll numbers to prevent duplicate entries.
- **File Handling:** Reading, writing, and persisting data using `with open("students.txt", ...)`.

---

## 📂 Programs & Files
1. [`student_record_management.py`](student_record_management.py) — Console-based Student Record Management System with add, view, and file persistence capabilities.
2. [`students.txt`](students.txt) — Flat-file database storing student records.
