# Day 5 – Pandas Practice & Dataset Analysis

- **Date:** 02 September 2026
- **Training Day:** Day 5
- **Focus Area:** Pandas DataFrames, CSV Loading, Null Detection, Conditional Filtering, and Summary Statistics

---

## 📖 Topics Practiced

- **DataFrame Creation & Inspection:** Loading tabular data with `pd.read_csv()`, previewing with `head()` and `tail()`.
- **Dimensionality & Nulls:** Checking `.shape` and detecting missing data with `isnull().sum()`.
- **Conditional Filtering:** Subsetting records using relational operators (`df['Salary'] > 70000`, `df['Department'] == 'Data Science'`).
- **Summary Statistics:** Generating statistical distribution metrics using `describe()`.
