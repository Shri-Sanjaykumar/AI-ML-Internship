# Python Practice — Day 2

This folder contains Python scripts created while practicing basic Python programming concepts during Day 2 of the internship.

---

## 📝 Concepts Practiced
- **Variables & Data Types:** Strings, integers, floats, booleans, and basic arithmetic.
- **Conditionals:** `if`, `elif`, and `else` statements for decision-making.
- **Loops:** `for` loop with `range()` and `while` loop for iteration.
- **Functions:** Defining functions, passing arguments, and returning values.

---

## 📂 Programs Created
1. [`python_practice.py`](python_practice.py) — Demonstrations of basic variables, data types, conditionals, loops, and simple functions.
2. [`student_grade_calculator.py`](student_grade_calculator.py) — Command-line program that takes subject marks, calculates total and average, and assigns a grade.
3. [`simple_calculator.py`](simple_calculator.py) — Calculator program using modular functions for addition, subtraction, multiplication, and division.
